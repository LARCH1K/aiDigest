# План реализации обратной связи по мониторингу

**Цель.** Внедрить показатели нацплана, уточнённые методики, мировой каталог и фильтр отрасли.

**Архитектура.** Python-пайплайн сохраняет проверенные свидетельства в существующем JSONB. FastAPI и React используют единый справочник. Яндекс ограничивает длину каждого запроса и учитывает каждый запрос в текущем бюджете.

**Спецификация.** `docs/superpowers/specs/2026-11-27-analytics-feedback-design.md`.

## Проверки

- [x] Справочник и обработчик `/api/meta` выдают номера и названия шести показателей. Классификатор принимает цитаты из известных источников и отвергает старые идентификаторы и выдуманный текст. Прежние записи читаются без связей с нацпланом. Карточка, фильтр и Excel используют новый справочник.
- [x] Пять критериев М-1 доступны в карточке и выгрузке, включая проверенные качественные свидетельства и пробелы. Отношение Р-1 доступно для проверенных фактических значений в одинаковых единицах с ненулевым знаменателем и явным порядком в цитате.
- [x] `/api/meta` возвращает отрасли из базы, `/api/cases` применяет отрасль вместе с остальными условиями, React ставит этот фильтр первым.
- [x] Каталог показывает ссылки источников. Запросы к Яндексу укладываются в 400 символов, включают все группы и укладываются в бюджет. Повторный офлайн-поиск использует кеш отдельных запросов.
- [x] Прогнать Python с PostgreSQL, тесты React и production-сборку. Проверить состав изменений перед коммитом.
