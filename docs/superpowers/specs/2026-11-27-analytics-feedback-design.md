# Обновление мониторинга по обратной связи аналитиков

Обновляем сбор, реестр и выгрузку, чтобы аналитики могли проверить связь регионального кейса с нацпланом, сравнить эффекты внедрения и отобрать кейсы по отрасли.

## Подход

Обновление подписей и справочников оставило бы прежнюю классификацию в API и превысило бы лимит длины поискового запроса. Обновляем классификацию, хранение связей и представление данных вместе. Для поиска с длинным списком доменов выполняем несколько запросов с тем же поисковым текстом.

## Требования

- Шесть показателей нацплана: 1.1 (70%), 1.2 (50%), 2.3 (60%), 3.1 (70%), 3.2 (100%), 3.3 (50%). Цели на 2030 год берём из материалов «Аналитики» и указываем отдельно от показателей кейса. Связь требует цитаты из известного источника. Архивные кейсы получают новые связи через штатное дозаполнение.
- М-1 содержит пять критериев, включая сопутствующие риски. В карточке каждого мирового государственного кейса видно, по каким критериям есть свидетельства и где данных недостаточно. Р-1 использует `Base / Project` для проверенных сопоставимых фактических значений. Для общего балла потребуются согласованные веса.
- Фильтр отрасли размещаем в начале списка. Регистронезависимые варианты и варианты с лишними пробелами объединяем.
- В мировой каталог добавляем 13 источников и Microsoft с двумя ссылками. Бюджет сбора задаётся существующими настройками. Пробный онлайн-сбор выполняется отдельно по запросу.
- Папка с обратной связью остаётся локальной. Бот Свердловской области вне объёма работ.
