# Поиск через Yandex Search API

## Цель

Использовать Яндекс для поиска кейсов и подтверждений по умолчанию. Сохранить Tavily как вариант для явного выбора при запуске. Интерфейс сбора показывает состояние и результаты в терминах, общих для обоих провайдеров.

## Выбор способа настройки

Переменная окружения `AIDIGEST_SEARCH_PROVIDER` принимает `yandex` (по умолчанию) или `tavily`. Этот способ выбран, потому что одинаково работает при запуске CLI и при запуске сбора из веб-интерфейса. Флаг CLI удобен для отдельных команд, но потребовал бы ещё одного способа передачи выбора из API в подпроцесс. Каждый запуск использует ровно одного провайдера, в том числе при ошибке поиска. Неизвестное значение считается ошибкой конфигурации.

В текущем Docker Compose переменная передаётся сервису `backend`, который запускает сбор наследующим окружение подпроцессом. Для Яндекса нужны `YANDEX_SEARCH_API_KEY` и `YANDEX_SEARCH_FOLDER_ID`, передаваемые из окружения или `secrets.env` по аналогии с текущими настройками. Онлайн-сбор проверяет настройки выбранного провайдера перед поиском. Офлайн-сбор работает с кешем выбранного провайдера без ключей и сети.

## Поиск и обработка

- Добавить реализацию существующего `SearchClient` через [синхронный REST API Яндекса](https://aistudio.yandex.ru/ru/docs/search-api/operations/web-search-sync). Разбирать XML, сохранять ограничение числа результатов, ограничения по доменам и окно свежести. Дату публикации записывать при наличии подтверждённых данных.
- Переиспользовать загрузку и кеширование текста статьи. Если загрузка недоступна, использовать поисковый фрагмент как доступный текст источника. Кешировать выдачу Яндекса отдельно от Tavily. Дозаполнение архива должно находить сохранённые материалы обоих провайдеров.
- Бюджет запуска ограничивает новые поисковые запросы, попадания в кеш бесплатны. Для Tavily сохранить сверку с месячным лимитом и ограничение по остатку. При выборе Яндекса обращаться только к его поисковому API.

## Веб-интерфейс

Убрать индикатор месячных кредитов и зависимость страницы запуска от `/api/credits`. Оставить статус, итог сбора, журнал и нейтральное сообщение о достижении лимита, если API отклонил запуск. Проверить также страницу запросов, ошибки, поля отчёта и показ исторических журналов. Существующий API кредитов можно сохранить для совместимости с другими клиентами.

## Проверка

Покрыть тестами выбор провайдера по умолчанию и через окружение, обработку XML, кеш и бюджет, запуск из API, обработку лимита Tavily и нейтральный вывод веб-интерфейса. Автоматические тесты используют подменённые сетевые вызовы.
