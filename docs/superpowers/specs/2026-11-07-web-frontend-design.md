# Веб-фронт aiDigest для «Аналитики» — design

Дата: 2026-11-07. Статус: черновик на согласование.

## Зачем

У пайплайна есть только консоль и Excel. Команде «Аналитика» нужна страница в браузере, чтобы:
- смотреть и фильтровать кейсы;
- открывать карточку кейса с цитатами и ссылками;
- скачивать Excel;
- **самим запускать сбор** новых кейсов.

Основные пользователи — «Аналитика», нетехнические люди. На первых порах страница работает на компьютере пользователя, «Аналитика» заходит по локальной сети. Позже её перенесут на сервер.

## Цели

- Три основные страницы по согласованным макетам: список кейсов, карточка кейса, запуск сбора. Плюс страница «Как читать таблицу» и выгрузка Excel.
- **Красиво без фреймворков:** аккуратная своя таблица стилей, понятная типографика, цветные статусы. Должно быть не стыдно показать.
- **Фронт легко удалить.** Он живёт в отдельной папке и **не меняет ни строчки кода пайплайна**. Удаление фронта = удалить папку пакета, его тесты и необязательную зависимость.

## Не цели

- Редактирование кейсов, источников, запросов и настроек через страницу.
- Учётные записи, роли, история «кто нажал».
- Выбор бюджета или уровней при запуске: запуск всегда обычный, до 30 кредитов.
- Развёртывание на сервере (позже, отдельно). Мобильная вёрстка — только «не разваливается».

## Анти-цели (провал, даже если «работает»)

- Фронт меняет код в `src/aidigest/`.
- Два запуска одновременно, то есть двойной расход кредитов.
- Запуск в обход месячного лимита.
- Фронт без пароля открыт в локальной сети.
- Показ данных, которых нет в базе: фронт только отображает то, что записал пайплайн.

## Ограничения

- Python, **Flask + Jinja2** (серверные шаблоны, аналог Thymeleaf). Без JS-фреймворков и CSS-фреймворков. Только свой CSS и немного чистого JavaScript.
- Без внешних CDN и шрифтов из интернета: в локальной сети интернета может не быть. Используется системный стек шрифтов.
- **Код пайплайна (`src/aidigest/`) не меняется.** Фронт может импортировать из него для чтения: модели, `CaseStore`, `export_excel`, `MonthlyUsage`, `load_settings`. Запуск сбора — только отдельным процессом через консольную команду `python -m aidigest run`.
- Пути к данным — те же, что у CLI: `AIDIGEST_DATA_DIR` или `data/`.
- Секреты (`litellm.env`, `tavily.env`, новый `web.env`) не читаются в логах и не отдаются браузеру.

## Как устроено (решения согласованы с пользователем по макетам)

### Размещение
- Пакет `src/aidigest_web/` с `templates/` и `static/` внутри. Тесты — `tests/web/`.
- Зависимости `flask` и `waitress` — в отдельном extra: `pip install -e ".[web]"`.
- Запуск: `python -m aidigest_web` (параметры `--host`, `--port`, по умолчанию `127.0.0.1:8000`).
- *Решение Claude:* сервер — `waitress`. Это лёгкий production-сервер на чистом Python: встроенный сервер разработки Flask не предназначен для доступа по сети. Состояние запусков в памяти процесса не хранится, всё лежит в файлах (см. ниже).

### Доступ
- Общий пароль в `web.env` (`WEB_PASSWORD`, по желанию `WEB_SECRET_KEY`). Файл в `.gitignore`.
- Пароль задан → все страницы требуют входа (страница «Вход», сессия Flask).
- Пароль не задан → разрешён **только** `--host 127.0.0.1`. Попытка открыть сервер в сеть без пароля — отказ с понятным сообщением.

### Страница «Кейсы» (`/`)
- Шапка с навигацией: Кейсы · Запуск сбора · Как читать таблицу; справа кнопка «Скачать Excel».
- Фильтры через обычную форму GET (работают без JS):
  - поиск по тексту — название, суть, регион, организация, технология;
  - уровень и статус подтверждения;
  - «только с цифрами» (по умолчанию включено);
  - «скрыть сомнительные» — кейсы с флагом `цифра_не_найдена_в_тексте` или `противоречие_источников`.
- Строка «Найдено N из M · база обновлена <дата изменения файла>».
- Таблица: уровень, регион, кейс (ссылка на карточку), главная цифра, стадия, статус (цветная метка).
  - **Главная цифра** — первая метрика с проверенной цитатой (`quote_verified`) в виде «название: было → стало (изменение)». Если проверенных нет — первая метрика с пометкой ⚠. Если метрик нет — «—». *(решение Claude)*
  - «Только с цифрами» значит «есть хотя бы одна метрика», как в Excel. *(решение Claude)*
  - ⚠ ставится, если у кейса есть любой флаг сомнения.
- Сортировка кликом по заголовку — маленький скрипт на клиенте. Порядок по умолчанию — как в Excel: с цифрами → подтверждённые → уровень.

### Карточка кейса (`/case/<id>`)
- **Шапка кейса:** заголовок и строка свойств — уровень, регион, организация, сектор, отрасль, технология, стадия, методика, статус. Ниже блок «суть».
- **Таблица показателей:** название, «было → стало (изменение)», критерий, дословная цитата со ссылкой на источник. Колонка «Проверка»: цитата найдена ✔ или ⚠, подтверждено источниками (ссылки), расхождения.
- **Источники:** домен, достоверность, тип.
- **Флаги:** каждый с пояснением «что значит» и «что делать» (тексты из README).
- Неизвестный id — страница 404 в общем стиле.

### Запуск сбора (`/run`)
- **Блок «Кредиты Tavily в этом месяце»:** потрачено и лимит, полоска-индикатор. Один запуск — до 30.
- **Кнопка «Запустить сбор»** (POST). Неактивна, если:
  - сбор уже идёт;
  - остаток месяца равен 0.
- **Запуск** — через маленькую обёртку внутри фронта: `python -m aidigest_web.runner <run_id>`. *(решение Claude)*
  - Обёртка вызывает `python -m aidigest run`; рабочий каталог — корень проекта, окружение — с тем же `AIDIGEST_DATA_DIR`.
  - stdout и stderr пишутся в `<data>/web/runs/<run_id>.log`.
  - По окончании обёртка записывает `<data>/web/runs/<run_id>.json`: время старта и конца, код выхода. Так итог запуска не теряется при перезапуске веб-сервера.
  - Обёртка запускается **отдельно от сервера**: в Windows — `CREATE_NEW_PROCESS_GROUP | DETACHED_PROCESS`, в Linux — `start_new_session=True`. Остановка или перезапуск веб-сервера не обрывает сбор.
- **Не больше одного запуска:** lock-файл `<data>/web/run.lock`, создаётся атомарно (`O_CREAT|O_EXCL`), внутри PID, время старта и путь к логу.
  - Если для запуска уже есть `<run_id>.json` или процесса с этим PID больше нет, запуск считается завершённым и lock снимается. Если обёртка умерла, не записав итог, статус — «прервано».
  - Проверка — при каждом обращении к статусу. Живость PID проверяется без новых зависимостей: `os.kill(pid, 0)` в Linux, `OpenProcess` через `ctypes` в Windows.
  - *Решение Claude:* блокировка защищает только запуски с сайта. Запуск из консоли (`python -m aidigest run`) она не видит, а обнаруживать чужие процессы без новой зависимости нельзя. В README появится предупреждение: не запускать сбор из консоли, пока идёт запуск с сайта.
- **Пока идёт сбор:** «⏳ Идёт сбор, начат в ЧЧ:ММ (N мин назад)», последние ~30 строк лога. Скрипт раз в 5 секунд опрашивает `/run/status` (JSON) и обновляет блок. Когда запуск закончился, страница перезагружается.
- **Итог последнего запуска:** время старта, длительность, код выхода (успешно или ошибка) и строки отчёта из его лога (строки вида «Ключ: значение», которые печатает CLI). История — 10 последних запусков списком: время и статус, ссылка на лог.
- Код выхода 2 (месячный лимит) показывается понятным текстом.

### «Как читать таблицу» (`/help`)
Статичный текст: уровни, методики (Р-1, М-1, бизнес-метрики), статусы, флаги, «главная цифра», откуда берутся данные. Тексты — по README, понятным языком.

### Excel (`/export.xlsx`)
Собирается из текущей базы через `export_xlsx` во временный файл и отдаётся как `aidigest_cases_<дата>.xlsx`.

### Внешний вид
- Светлая тема, свои CSS-переменные для цветов. Спокойный нейтральный фон, один акцентный цвет.
- Статусы — цветные «таблетки»: подтверждено — зелёная, один источник — жёлтая, противоречие — красная.
- Таблицы с выделением строки при наведении и липкой шапкой. Карточки с мягкой тенью, аккуратные отступы.
- Системный стек шрифтов. Ширина контента ограничена и центрирована.
- Шрифт и контраст читаемы. Внешний вид проверяется скриншотами в браузере.

## Что оставлено builder'у
- Структура модулей внутри `aidigest_web`, имена маршрутов-функций, разбиение шаблонов (`base.html` + страницы).
- Точная палитра и вёрстка в рамках описания выше.
- Как разбирать строки отчёта из лога.
- Тесты: Flask test client на все страницы, логику фильтров, вход и отказ без пароля, lock (двойной запуск запрещён), запуск через подменённый `Popen`. Без сети и без настоящего пайплайна.
