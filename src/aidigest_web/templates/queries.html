Поисковые запросы

С какими запросами сбор ищет статьи о внедрении ИИ. Страница только показывает настройку: список правится в файле config/queries.yaml и попадает сюда после выкладки.

Что означают поля

Уровень
Для какого уровня подобран запрос: мир, регионы РФ или Свердловская область. От него зависит набор сайтов при поиске «только по справочнику». Уровень самого кейса определяется по тексту статьи (страна, регион) и может отличаться от уровня запроса.
Текст запроса
Фраза, которую сбор отправляет в поисковый сервис Tavily. Ищутся статьи за последние {{ freshness_days }} дн. (настройка freshness_days). Каждый запрос стоит 1 кредит Tavily (лимит — 1000 в месяц).
Только по справочнику
да — поиск идёт только по сайтам из справочника для этого уровня (см. «Источники»): результаты надёжнее, но уже. нет — поиск по всему интернету: шире, но больше случайных статей.
Язык
На каком языке написан запрос; для мирового уровня часть запросов на английском.
